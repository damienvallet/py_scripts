# py_scripts
Some Python scripts created during spare time for various purposes.

- **Random Tape Splicer.py**:
  - This script simulates the process of cutting a tape into pieces, throwing it away, and splicing it back randomly. It was inspired by old tape machines generative music techniques.

- **create_dummy_move.py**:
  - This script creates an dummy .mov video file with a specified duration and resolution. It generates a black video with a white rounds and lines appearing at random locations.

- **generate_image_from_wavfile.py**:
  - This script generates a plot of a wav file and saves it as a png image.
